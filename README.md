# 九霄来信 · 纸飞机冒险

一封想寄往天空尽头的信，折成纸飞机，从山谷一路飞向星海。这是带完整起飞、五段旅程、失败重试与结局的纵向射击游戏，浏览器版和原生微信小游戏共用玩法与画面。

当前版本：**2.2.0**。天气危险更密集，月光动物更耐打、技能释放更快；雪林加入会造成伤害的大雪团。四幅本地生成插画呈现晨曦山谷、霞光云海、雪线森林与九霄星海，随飞行缓慢推进，换章时平滑过渡；六种动物使用透明图集，配合各自的飞行动作、受击与消散反馈。

## 这一程怎么玩

纸飞机从地面起飞，初始生命 **100**。自由上下左右移动，躲开敌方弹幕、雨滴、大雪团、冰雹与可见的阵风团，飞到 **9000 米** 收到终章；完整旅程约 **270 秒（4.5 分钟）**。

- 默认自动射击，也可关闭后按住「发射」。基础风弹不消耗资源，星能用完仍能继续开火。
- 拾取金色星星补充 **12 点星能**，射出伤害 2 的星光弹；无限基础风弹伤害 1。
- 天空中的月兔、星鹿、云鲸、雪狐、月蝶与霜隼会移动、蓄力并发射紫色弹幕。每次击败必掉绿色治疗光点，拾取恢复 **22 生命**；首次击败即加入图鉴，也可能额外掉落星能。
- 天气危险到来前会出现提示，每波留有躲避空隙。雨、雷雨、雪团、冰雹与更强的横风随故事推进；装饰雨线增至最多 260 条、雪花最多 190 片。舒缓模式减少装饰雨雪并关闭闪电。
- 生命归零可以重新起飞；图鉴、最高高度与通关记录会保留。

飞机现在会轻柔加速、带着惯性转弯，松开后迅速收稳，侧倾跟随真实移动。月兔跃动、星鹿轻跳、云鲸缓游、雪狐转折、月蝶振翅、霜隼俯掠；动物蓄力时先锁定方向，再发射弹幕，留出躲避空间。飞近补给会触发柔和吸附，星光弹带有限的轻微引导，仍需选择合适的射击航线。

故事经过山谷起风、穿过晚霞、风暴来信、雪落森林、星海守望，抵达「信抵达的地方」。前 6 秒是受保护的起飞动画；天气攻击会提前 1.8 秒提示，受击后有 0.85 秒保护。细小雨雪和闪电属于氛围，真正的天气危险是较大的蓝色雨滴、大雪团、冰雹与阵风团。治疗仍恢复 22 生命，难度与章节规则见 [GAMEPLAY.md](GAMEPLAY.md)。

## 操作

| 操作 | 浏览器 | 微信小游戏 |
| --- | --- | --- |
| 上下左右移动 | 移动鼠标让飞机跟随目标；拖动天空或方向键 / WASD | 在天空中二维拖动 |
| 射击 | 默认自动；关闭自动后按住空格或「发射」 | 默认自动；可一指移动、另一指按住「发射」 |
| 暂停与继续 | 上方暂停按钮、P 或 Escape | 上方暂停按钮 |
| 图鉴 | 点击图鉴或 J，关闭后回到原状态 | 点击图鉴，关闭后回到原状态 |
| 环境音与舒缓 | 上方按钮；M 切换声音、C 切换舒缓 | 上方声音与舒缓按钮 |

声音默认关闭，需要主动开启。离开页面或微信切后台会暂停，回来后点击继续；暂停与图鉴期间不会受到伤害或推进旅程。

## 本地运行

安装 Node.js 后在项目目录运行，无需安装依赖：

```bash
node serve.cjs
```

打开 [http://127.0.0.1:8080](http://127.0.0.1:8080)。也可直接打开 `dist/index.html`；若浏览器限制本地文件存储，使用本地服务。更多操作见 [RUNNING.md](RUNNING.md)。

分发网页版时完整保留 `dist/` 目录，插画和透明动物图集位于 `dist/assets/art/`，与页面通过相对路径加载；运行时无需从外网下载画面素材。美术使用内置图像生成工具制作，提示词主题、成品路径与发布规格见 [ART-DIRECTION.md](ART-DIRECTION.md)。

微信版本位于 `wechat-minigame/`，AppID 为 `wxedf8b0ff920cc0ee`。导入与上传步骤见该目录的 `README.md`、`UPLOAD.md`。

## 存档与验证

新玩法使用 `windborne.adventure.v1` 本地存档，**只保存已收集的动物图鉴、最高高度和通关次数**；当前一局的生命、位置、子弹与进程不续存，重新打开从首页开始。之前漫游版的存档独立保留。浏览器各来源与微信设备之间不共享进度，没有账号、云存档、广告或支付。

完整仓库中运行：

```bash
node tools/build-wechat.cjs
node tools/check-wechat.cjs
node --test tests/*.test.cjs
```

`dist/adventure.js` 管理战斗、惯性运动与动物行为，`dist/view.js` 绘制共享画面，`dist/scenery.js`、`weather.js` 绘制天空与天气，`dist/assets.js` 加载本地美术，`dist/game.js` 负责浏览器交互。原生微信适配位于 `wechat-minigame/src/main.js`；共享模块及美术由构建工具同步，修改后需重新构建。微信开发者工具与 iOS/Android 真机仍需按 `wechat-minigame/UPLOAD.md` 验证，本地预览不能代替真机验收。
