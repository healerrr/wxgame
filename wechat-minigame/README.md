# 九霄来信 · 微信小游戏版

版本：`2.2.0`；AppID：`wxedf8b0ff920cc0ee`。这是原生 Canvas 微信小游戏，入口 `game.js`，可直接导入微信开发者工具。

本版提高天气密度、动物生命与技能频率，并加入会造成伤害的大雪团。晨曦山谷、霞光云海、雪线森林与九霄星海四幅生成插画、六种动物透明图集、惯性转向和分种动作继续保留。图片位于包内 `assets/art/`，运行时无需外部素材域名。

## 导入

1. 使用微信开发者工具的「小游戏」入口导入本目录。
2. 确认 AppID 与项目类型为小游戏，基础库使用工具当前稳定版本。
3. 点击编译，无需 npm install、本地服务器或外部资源域名。
4. 用开发成员账号扫码预览，在真机检查后再上传。

## 飞向天空尽头

一封未寄出的信折成纸飞机，初始生命 **100**，经过 6 秒受保护的起飞，穿过山谷、晚霞、雷雨、雪林与星海。达到 **9000 米** 收到终章，完整旅程约 **270 秒（4.5 分钟）**。

- 在天空中二维拖动，上下左右移动与躲避。飞机平滑加速、带惯性转向，松开后迅速收稳。
- 默认自动射击。可关闭自动射击，一指拖动、另一指按住「发射」。
- 金色星星补充 12 点星能，星光弹伤害 2；星能用尽仍可无限使用伤害 1 的基础风弹。
- 月兔跃动、星鹿轻跳、云鲸缓游、雪狐转折、月蝶振翅、霜隼俯掠。动物更耐打，后续攻击间隔约 2.6–3.8 秒，3600 米后每次再加一发；约 0.9 秒蓄力时先锁定方向。受击发亮，击败后消散并加入图鉴，每次必掉治疗光点，拾取恢复 22 生命，也可能额外掉落星能。
- 天气攻击提前 1.8 秒提示，每波留出空隙；躲避较大的蓝色雨滴、大雪团、冰雹与可见风团。普通横风只推动位置，风团碰撞扣 5 生命；雨滴、大雪团、敌方紫色弹幕、冰雹分别扣 6、7、9、12 生命，受击后有 0.85 秒保护。
- 装饰雨线最多 260 条、雪花最多 190 片，细小装饰雨雪不造成伤害。舒缓模式仍减密度并关闭闪电；真实天气危险和战斗规则保持一致。
- 上方可打开图鉴、舒缓、声音与暂停。声音默认关闭，需主动开启。
- 切后台自动暂停，回来后点击继续。生命归零可重新起飞。

## 本地进度

存档键 `windborne.adventure.v1`，只保存六种动物图鉴、最高高度与通关次数。当前一局的生命、位置和进程不续存，重新打开从首页开始。重试保留图鉴与纪录，之前漫游版存档独立保留。

存档属于当前微信设备，不与浏览器或其他设备共享。没有账号、广告、支付或云存档；存储或声音不可用时仍可游玩。

## 运行与维护

入口通过 `wx.createCanvas` 绘图，使用原生触摸、窗口安全区、微信右上角胶囊避让与前后台生命周期。合成环境音优先使用 Web Audio，不支持时尝试包内音频。

`src/adventure.js`、`view.js`、`scenery.js`、`weather.js` 与美术加载模块来自浏览器共享源码；`src/main.js` 是原生输入和生命周期适配。完整仓库运行：

```bash
node tools/build-wechat.cjs
node tools/check-wechat.cjs
node --test tests/*.test.cjs
```

构建会同步共享模块及本地美术；分发时保留整个小游戏目录。构建和测试工具不需要上传。开发工具可用 `GameGlobal.windborne.getState()` 只读检查状态，上传与真机验收见 `UPLOAD.md`。当前本地检查不代表微信开发者工具或 iOS/Android 真机已经通过，仍需按清单预览验收。
