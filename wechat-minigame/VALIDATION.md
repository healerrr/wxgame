# 2.2.0 交付验证记录

版本：`2.2.0`；AppID：`wxedf8b0ff920cc0ee`。当前工程为《九霄来信》纵向射击冒险，含起飞、五段旅程、失败重试、9000 米结局与六种动物图鉴。本版提高天气危险密度、动物生命及技能频率，增加可碰撞大雪团；四幅插画、六动物图集与惯性操作继续保留。

## 本地验证

测试覆盖战斗与补给、起飞和结局、图鉴与纪录存档、浏览器输入、原生二维触摸与双指射击、图鉴暂停返回、前后台、窗口变化、声音与存储不可用时的回退，以及天气渲染。2.2.0 需重点复核提高后的动物血量与技能节奏、密集天气仍有可躲避航线、大雪团碰撞扣 7 生命，以及狂风碰撞扣 5 生命。1.8 秒天气预警、0.9 秒蓄力、0.85 秒受击保护和每次击败掉落 22 生命治疗应保持有效。

2026-10-23 最终结果：**41 项自动化测试全部通过**，2.2.0 构建、共享源码和图片哈希检查通过。完整微信工程约 **3.54 MiB**，低于项目的 4 MiB 预算。已在浏览器查看真实公开输入所得的暴雪章节，确认大雪团、风团和浓雪层正常显示。装饰天气正常模式雨线最多 260 条、雪花最多 190 片，粒子池上限固定为 450，舒缓减密度与禁闪电保持有效。

用 29、31、42 三个种子进行公开输入模拟：静止自动射击两局分别在约 6292 米与 7458 米失败，另一局抵达终点剩余 19 生命；持续左右走位三局均通关，剩余生命为 70、79、92。追踪目标并避弹仍可稳定通关，验证难度确实提升且有可行路线。完整旅程回归还检查高空同种动物更耐打、实际月光弹与天气危险生成率上升。

完整仓库中的检查命令：

```bash
node tools/build-wechat.cjs
node tools/check-wechat.cjs
node --test tests/*.test.cjs
```

构建同步战斗、共享画面、天空、天气及美术加载模块，并复制 `assets/art/` 中的插画和图集；`build-info.json` 记录版本、源码及图片哈希。原生入口、小游戏配置、AppID、模块同步、图片与整个目录包体检查由 `check-wechat.cjs` 执行。

浏览器和本地原生 Canvas 宿主可检查画面及交互，但均不等于微信开发者工具或 iOS/Android 真机验证。

## 发布前仍需验证

1. 账号持有人用当前官方稳定版微信开发者工具和本 AppID 编译。
2. 按 `UPLOAD.md` 在目标 iOS/Android 手机完成起飞、移动射击、掉落拾取、天气、暂停、失败重试和结局检查；确认四幅插画、六动物透明边缘、换章过渡与动画正常。
3. 确认图鉴与纪录保留，重启不会恢复上一局；检查刘海、安全区、胶囊和双指触控。
4. 检查账号权限与后台要求后上传开发版，再完成体验、审核与发布流程。
